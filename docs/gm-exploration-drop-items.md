# ไอเท็มดรอปสำรวจในวัง — ข้อเสนอสำหรับ GM

> **ลับเฉพาะ GM** รายการนี้เป็นไอเดียออกแบบจากโลกและพล็อตที่ให้มา ไม่ใช่ไอเท็มซึ่งต้นฉบับกำหนดไว้แล้ว ห้ามนำคำอธิบาย “เฉลย/ไปหาใคร” ในตารางนี้ไปแสดงฝั่งผู้เล่น

ใช้ร่วมกับ [ไอเท็มหลักฐานและรูทจบ](gm-route-key-items.md) และแผนที่วังหมายเลข 1–32 ในระบบสำรวจ ผู้เล่นกดสำรวจแล้วระบบสุ่มผลและเลข d100; สต๊าฟเห็นเลขและเลือกไอเท็มเอง งานที่สำเร็จได้ของไม่เกิน **หนึ่งชิ้น** ส่วนงานไม่สำเร็จไม่ได้ไอเท็มตามระบบปัจจุบัน ตารางข้างล่างจึงเป็น **รายการให้สต๊าฟเลือก** ไม่ใช่คำสั่งให้ระบบแจกอัตโนมัติ

## หลักการแจก

1. ของทั่วไปมีไว้ให้โลกมีชีวิตและใช้โรลเพลย์ได้ ไม่ต้องเป็นเบาะแสทุกครั้ง
2. ของเบาะแสจากการสำรวจควรเป็น **เศษข้อมูลที่ชี้ไปหาคนหรือสถานที่** ไม่ใช่หลักฐานเต็มของ NPC หลัก และไม่เฉลยว่าฮ่องเต้เป็นใคร
3. เลข d100 สูงอาจเพิ่มความหายากหรือความชัดของเบาะแส แต่ **หลักฐานจำเป็นต่อรูทจบต้องมีทางเข้าถึงผ่านการเล่นอื่นเสมอ** ไม่ล็อกไว้ที่เลข 95–97 หรือโอกาสสุ่มครั้งเดียว
4. จุดที่ปิด พื้นที่จำกัด และเอกสารในห้องเก็บลับยังต้องให้สิทธิ์หรือ GM เปิดฉากก่อน ของดรอปไม่เป็นกุญแจข้ามกฎเข้าพื้นที่
5. ระวังความน่าเชื่อของสถานที่: เอกสารของตระกูลที่อยู่ต่างหัวเมืองไม่ควรนอนอยู่กลางสวนวังโดยไม่มีเหตุผล ถ้าจะใช้ ให้เป็นจดหมายส่งเข้าเมืองหลวง สำเนาคำขอ หรือใบเบิกที่มีที่มา

## ของหายากที่ชี้รูท แต่ไม่ข้ามขั้นสืบ

ของกลุ่มนี้เหมาะกับช่วงที่ผู้เล่นเปิดพล็อตแล้ว หรือ GM จัดอีเวนต์เฉพาะ **ไม่ใช่รางวัลเลขสูงที่แจกได้ตั้งแต่วันแรก**

| ไอเท็ม | วิธีได้ที่เสนอ | ปลายทาง |
| --- | --- | --- |
| **กุญแจหีบแผนที่ฉบับเก่า** | เฮ่อเหลียนยอมให้ หรือภารกิจที่เขาตั้ง | ไปหา E01; กุญแจไม่ยืนยันว่าในหีบมีอะไร |
| **จดหมายแนะนำตัวถึงช่างเหมืองผู้รอดชีวิต** | ฟางหรือกู้มอบเมื่อผู้เล่นตามเบาะแส C03/C04 | เข้าถึงพยาน E02/E03 |
| **ป้ายอนุญาตคัดเวชระเบียนหนึ่งหน้า** | เวินยอมให้หลังฉากตรวจความไว้วางใจ | เปิด E05 เพียงบางส่วน ไม่ใช่ยึดแฟ้มทั้งหมด |
| **รหัสอ่านจดหมายจากวัดตะวันออก** | เสิ่นต่อรอง หรือผู้เล่นถอดจากร่องรอย C09 | ตาม E10; ต้องไปพบคนจริงจึงยืนยันตัว |
| **ตรารับรองพยานร่วมสองฝ่าย** | ให้หลังผู้เล่นนำหลักฐานจากอย่างน้อยสอง NPC มาประกบ | เป็นเครื่องมือเปิดเวทีไต่สวน ไม่ใช่หลักฐานใหม่ |

## แนวทางเลข d100 สำหรับสต๊าฟ

หากต้องการใช้เลขที่ระบบสุ่มไว้ช่วยเลือกของ ให้ตั้ง **ตารางแยกแต่ละพื้นที่** ตามที่คุยกัน ไม่ใช้ช่วงเดียวทั้งวัง ตัวอย่างเริ่มต้นที่ปรับได้:

| เลข | ประเภทผลในพื้นที่หนึ่ง ๆ |
| --- | --- |
| 01–60 | ของทั่วไปหรือของใช้โรลเพลย์ |
| 61–84 | ของทั่วไปที่โยงคน/งานในพื้นที่ หรือเบาะแสอ่อน |
| 85–94 | เบาะแสชัดขึ้น เช่น C01–C12 เมื่อพล็อตเปิดถึงจุดนั้น |
| 95–97 | ของหายากด้านเนื้อเรื่อง เช่น สิทธิ์เข้าพบพยานหรือกุญแจ **เมื่อ GM เปิดเงื่อนไขแล้ว** |
| 98–100 | ของหายากพิเศษของพื้นที่ หรือฉากพบพยานที่น่าสนใจ; ไม่แจกความจริงทั้งสองชั้น |

ถ้าผู้เล่นทอยเลขสูงก่อนเปิดพล็อต ให้แจกของมีค่า/มีเรื่องเล่นของพื้นที่นั้นแทนเบาะแสลับ และบันทึกเลขไว้ให้สต๊าฟอ้างอิง ไม่มีการเปลี่ยนเลขย้อนหลัง ส่วนผู้เล่นที่เลขไม่สูงยังตามหลักฐานหลักได้ด้วยการสืบ สร้างความไว้ใจ และทำอีเวนต์

## ผูกเบาะแสกับรูท

- **ปกป้องหลินอัน:** C05, C07 และ C11 ทำให้เห็นราคาของการปิดความจริงและคนที่จะคัดค้าน
- **คืนบัลลังก์ให้เซียวอวี่เหิน:** C03 + C04 + C09 นำไปหาหลักฐานอุโมงค์และตัวจริง; C01/C12 ช่วยหาพยานทหาร
- **สละอำนาจเงียบ ๆ:** C01, C05, C06 ชี้ผู้ถือเอกสารและฝ่ายที่ต้องเจรจาเพื่อไม่ให้เกิดการล้างแค้น
- **ยอมรับชื่อหลินอันและให้แผ่นดินตัดสิน:** C02 + C08 เป็นทางเริ่มถามเรื่องตัวตนชั้นสอง; C07 พาเข้าสู่คำถามเรื่องความชอบธรรม

อย่าแจกหยกไหม้เกรียม ทะเบียนประสูติเต็มเล่ม เวชระเบียนสองชุด หรือ “แฟ้มสรุปทุกอย่าง” จากช่องสำรวจธรรมดา ของเหล่านี้มีผู้ถือและมีราคาทางการเมืองในต้นฉบับ ควรได้จากการพบ NPC การต่อรอง หรือฉากเปิดหลักฐานที่ผู้เล่นเป็นคนผลักดัน
